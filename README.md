# NEXUS — Intelligence Workspace 🧠✨

NEXUS is a premium, browser-native AI chat application built entirely with **Vanilla JavaScript, HTML, and CSS**. It is designed to be fast, private, and beautiful — with zero frameworks and zero build steps.

🔗 **Live Demo:** [https://shahzaib-io-dev.github.io/shahzaib-nexus/](https://shahzaib-io-dev.github.io/shahzaib-nexus/)

## ✨ Features

- **Bring Your Own Key (BYOK):** Add your OpenAI API key to unlock GPT-4o-mini for real, unlimited AI power.
- **Local Fallback Engine:** No API key? No problem. NEXUS has a built-in, on-device knowledge base for common coding questions.
- **Voice Input:** Speak your prompts using the Web Speech API.
- **Text-to-Speech:** Listen to AI responses with a single click.
- **Chat Folders:** Organize your conversations into custom, color-coded folders.
- **Attachments:** Upload images (vision support with API key) and text files.
- **Markdown Support:** Beautiful rendering for code blocks, bold text, and lists.
- **Keyboard Shortcuts:** Navigate like a pro (`Ctrl+K` for commands, `?` for help).
- **Dark & Light Mode:** Fully themed UI.
- **LocalStorage:** All your chats and settings stay 100% on your device. No tracking, no servers.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Storage:** Browser LocalStorage
- **APIs:** OpenAI API (Optional), Web Speech API, Speech Synthesis

## 🚀 How to Run Locally

Since NEXUS has no dependencies, running it is simple:
1. Clone this repository.
2. Open `index.html` directly in your browser.
3. *Optional:* Use a local server like Live Server (VS Code extension) for the best experience.
